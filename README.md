# lerex

Lerex — real-estate landing page (LUXEON design replica, rebranded).

Paper-toned editorial layout: split hero headline, horizontal
featured-listings rail, about + stats strip, regional broker grid.

## Stack

Vite + React + TypeScript + Tailwind CSS v4 (Inter Variable).

## Develop

```bash
pnpm install
pnpm dev     # http://localhost:5173
pnpm build   # production build to dist/
```
